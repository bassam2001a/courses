# مكتبة كورساتي

موقع شخصي بسيط (صفحات ثابتة) فيه كورسات الدراسة بالترتيب:

- `index.html` — الصفحة الرئيسية وأقسام الكورسات.
- `aplus.html` — دروس CompTIA A+ بالترتيب مع تتبع التقدم وملاحظات لكل درس.
- `data/aplus.js` — بيانات الدروس (العنوان، مدة الدرس، معرّف فيديو يوتيوب).
- `assets/` — التنسيق والسكربت.

التقدم والملاحظات بيتحفظوا محليًا في المتصفح (localStorage)، مفيش حسابات ولا سيرفر.

## تشغيل محلي

افتح `index.html` في المتصفح، أو:

```bash
python3 -m http.server 8000
```
